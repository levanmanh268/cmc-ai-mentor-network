# Demo information security policy (fictional)

Access tokens and API keys must be stored in environment variables or an approved secret manager, never committed to public source code. Access to enterprise documents follows a least privilege model. A document labelled confidential must not be uploaded to an unapproved external AI provider.

If a potential secret is leaked, revoke the key, rotate credentials, and document the incident in the approved security workflow. This is synthetic training content, not an official corporate policy.
